#  Diabetes Classification Using Machine Learning

##  Project Overview

This project uses Machine Learning to classify individuals into three categories based on their health, lifestyle, and demographic information:

-  Healthy
-  Prediabetes
-  Diabetes

The project uses the Diabetes Health Indicators Dataset (BRFSS 2015) and applies a Random Forest Classification algorithm to predict the diabetes category of an individual.

> **Note:** This project is intended for educational and machine-learning purposes only. The predictions should not be considered a medical diagnosis.

---

##  Objective

The main objective of this project is to develop a multiclass classification model that can predict whether an individual is:

0 → Healthy
1 → Prediabetes
2 → Diabetes
